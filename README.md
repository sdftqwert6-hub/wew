# Портфолио веб-дизайнера

## Описание проекта

Учебный сайт-портфолио для демонстрации работ и практических навыков в веб-разработке. Страница содержит краткое описание проекта и список учебных работ.

## Используемые технологии

- HTML
- CSS
- Git

## Структура проекта

- `index.html` — основная страница портфолио
- `style.css` — оформление страницы
- `.gitignore` — список файлов, которые Git не должен отслеживать
- `README.md` — описание проекта

## Запуск проекта

Откройте файл `index.html` в любом современном браузере.

## Проверка `.gitignore`

Файл `test.log` создан как тестовый пример и игнорируется правилом `*.log`. Его можно проверить командой:

```bash
git check-ignore -v test.log
```

## Работа с Git

теперь мы вносим изменения


git add .
git commit -m "Подготовлен проект для размещения на GitHub"
git log --oneline
```

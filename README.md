
## Запуск проекта

Откройте файл `index.html` в любом современном браузере.

## Проверка `.gitignore`

Файл `test.log` создан как тестовый пример и игнорируется правилом `*.log`. Его можно проверить командой:

```bash
git check-ignore -v test.log
```

Учебный веб-проект

Описание проекта

Данный веб-сайт создан в рамках практических занятий по разработке веб-сайтов. Проект предназначен для изучения HTML, CSS и JavaScript.

Основные возможности

Просмотр главной страницы.

Навигация по сайту.

Поиск информации.

Фильтрация проектов по категориям.

Удобный и простой интерфейс.

Используемые технологии

HTML5 — создание структуры сайта.

CSS3 — оформление и дизайн.

JavaScript — интерактивные функции.

Структура проекта

index.html — главная страница сайта.

style.css — файл оформления.

script.js — JavaScript-функции.

images/ — папка с изображениями.



Скачать или клонировать репозиторий.

Открыть папку проекта в Visual Studio Code.

Открыть файл index.html в браузере.

Пользоваться сайтом.
